# Survive in Moon — play it

A lunar survival game built on real NASA data, by **TAY Team** (Tima · Aisha · Yunus) for the
NASA Space Apps Challenge 2026 — *Junior Astronaut Mission Trainer*.

Run a crashed crew's outpost on the Moon: balance **life support, radiation shielding, power and food**,
salvage the wrecks, build a rover and repair the ship to fly home.

## Download & play (Windows 10/11, 64-bit)

1. Open **[Releases](../../releases/latest)** and download **`SurviveInMoon-Windows.zip`** (≈72 MB).
2. Right click the zip → **Extract All**.
3. Open the extracted folder and double click **`Survive in Moon.exe`**.

> Windows may show *"Windows protected your PC"* because the game isn't code-signed.
> Click **More info → Run anyway**.

## Controls

| Key | Action |
|---|---|
| W A S D | Move |
| Shift | Run |
| F | Use / pick up / talk to the crew |
| Tab | Inventory (right click an item to eat / drink / use) |
| M | Map (click to place a waypoint) |
| Right mouse | Look around |
| Esc | Pause |

## Real NASA data inside

| Source | Used for |
|---|---|
| **DONKI** — Space Weather Database (NASA CCMC) | Every in-game radiation storm is a real solar flare from the last year |
| **RadLab** — NASA OSDR, LRO/CRaTER | The radiation dose on the lunar surface and how strong storms get |
| **OSDR** biology studies (Veggie) | The greenhouse crops |
| **EPIC** — api.nasa.gov (DSCOVR) | The Earth in the lunar sky is a real photo |
| **LRO / SVS CGI Moon Kit** | The Moon in the story |

All data is stored inside the game — no internet connection needed.
